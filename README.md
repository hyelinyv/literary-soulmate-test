# 你的灵魂，与谁同频？

手机优先的文学知音测试：24道原创问题，12位作家与哲学家。浅色背景、柔和彩色光晕、通透卡片、平面剪影与抽象图形。

当前内容：`q24-v1.3-beta1`。匹配规则：`m1.1-editorial`。

本轮按确认稿保留伍尔夫的“感受捕手”，将鲁迅改为“呐喊者”、阿伦特改为“公共行动者”。Q18区分回应有限时的发声、不同人的公共参与、建议可行性与使用者责任，其余23题保留。结果说明、原文依据和鲁迅的《呐喊》阅读推荐同步调整。

## 本地运行

使用Node.js 24或更新版本，无需安装第三方依赖：

```sh
npm run dev
```

打开终端显示的本地地址。页面文件在 `dist/`，可部署到支持HTTPS的静态网站托管服务。

```sh
npm run build
npm test
```

构建命令从 `content-source/unified-input.json` 生成网页内容、数据和资料页；测试检查题库版本、名称、Q18理由区分、旧进度隔离、证据引用、同分处理与12种结果可达性。

## 文件入口

- `dist/app.js`：答题、结果、进度保存、结果卡与主动复制反馈。
- `dist/engine.js`：匹配计算。
- `content-source/unified-input.json`：题目、人物与候选映射的编辑源文件。
- `content-source/questions-v1.3.json`：当前确认的24题快照；v1.1快照保留作历史对照。
- `docs/匹配规则与核对.md`：规则、命名、Q18修订与研究边界。
- `设计说明.md`：完整文件说明与部署准备。

## 内容与试测边界

人物及共鸣类型围绕所列作品的局部主题展开，属于有文本依据的编辑匹配；不是经过信效度验证的心理量表，也不是历史人物的模拟答卷。原文出处与定位在结果页和资料页可查，不展示匹配准确率或百分比。

答题进度仅保存在当前浏览器，不自动上传。结果卡不包含逐题答案；试答者可主动复制反馈及答题记录，自行发送给组织者。程序案例不代表真人样本。
